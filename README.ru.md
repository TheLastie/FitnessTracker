# Fitness Tracker

**Русский** | [English](README.en.md)

Настольный трекер на Python для питания, состава еды, тренировок и ежедневного потребления воды; есть экраны регистрации и входа, светлая и тёмная темы.

## Что находится в репозитории

- Файлы UI, созданные в Qt Designer, описывают экраны входа, еды, тренировок, воды и настроек.
- Модули Python обрабатывают регистрацию, записи о еде и настройки.
- Зависимости перечислены в `requirements.txt`; в репозитории также есть примеры данных и значки.

## Запуск и настройка

Создайте окружение Python, установите зависимости из `requirements.txt` и запустите `python main.py` из корня репозитория.

## Примечания

Это учебный прототип. Перед использованием личных данных проверьте, как хранятся учётные записи и пользовательская информация.
