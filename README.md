# Fitness Tracker

[Русский](README.ru.md) | **English**

A Python desktop tracker for meals, nutrition, workouts, and daily water intake, with registration/login screens and light/dark themes.

## Included in this repository

- Qt Designer UI files define login, meal, exercise, water, and settings screens.
- Python modules handle registration, meal entries, and settings.
- `requirements.txt` lists the runtime dependencies; sample meal data and icons are included.

## Getting started

Create a Python environment, install `requirements.txt`, then run `python main.py` from the repository root.

## Notes

This is an educational prototype. Review how account and user data are stored before using it with personal information.
